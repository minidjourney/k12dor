# 지원 경계와 미검증 사항

등록·구현·합성 시험·실제 제공자 조회·다른 PC 배포는 서로 다른 완료 조건입니다.

## 등록 수와 실제 가용성

전체 등록은 146개이며 권한 manifest는 READ 142 / WRITE 4입니다. READ 권한의 53개는 무전송 차단으로 분류됩니다. 로컬 전용·참고정보·이미지·채널 조회 등도 섞여 있으므로 이를 "142개 API 실조회 성공"으로 읽지 마세요. [전체 도구](TOOLS.md)에서 이름별 분류와 인자를 확인하세요.

도구의 `read` 표시는 권한 경계이며 HTTP GET 전용이라는 뜻은 아닙니다. 예를 들어 네이버 인증 토큰 발급에는 POST가 사용됩니다. 조회형 POST·계정 연결·미확정 효과 GET·등록/수정/삭제 등은 개별 구현과 승인 계약을 따르며 무조건 실행하지 않습니다.

## 채널별 제한

- 쿠팡 일반: 상품·주문 등 공용 조회와 브랜드/카테고리/여러 독립 GET이 구현돼 있습니다. 주문 linkage·쿠폰 일부·계정/미확정 GET은 전송 전에 차단될 수 있습니다.
- 로켓그로스: 일반 판매자배송 API와 혼용하지 않습니다. 상품·고유 가격·재고·RG 주문 목록/단건·RFM 카테고리/메타 등의 독립 경로를 구분합니다. 범용 주문 상세/클레임/정산/수수료의 RG 지원 근거가 없는 기능은 보류·미지원으로 남습니다.
- 네이버: 공용 조회·원상품/채널상품·카테고리·등록 참고정보·SKU/정산/배송 관련 일부 GET 등이 구현돼 있습니다. 이미 등록한 상품에서 원산지·고시·A/S 안내·배송 등 정해진 등록값만 읽는 도구가 있습니다. 일부 클레임의 HTTP 400 원인, 문의 조건 차이, 즉시할인 관련 관측 ID 공백 등은 해결 완료로 주장하지 않습니다. SKU v1은 폐기 예정 계약의 제한된 별도 경로입니다.
- 네이버 옵션 이미지: 공식 표준옵션 이미지 구조와 합성 시험을 지원합니다. 확인한 실제 표본에서는 이미지 그룹을 가진 상품이 없어 **실양성 검증은 미완료**입니다. 그룹 없음이 네이버의 옵션 이미지 기능 부재라는 뜻은 아닙니다. 등록 초안의 추가 사진(`optional_images`, 최대 9장)은 옵션과 묶이지 않는 일반 추가 사진입니다.
- 쿠팡 상품 본문 사진: 한 상품의 사진이 100장을 넘으면 역할 순서(대표 > 추가·옵션 > 미분류 > 상세)로 100장만 돌려주고 결과를 incomplete(`image_count_truncated`)로 표시합니다.
- 토스 쇼핑: 모든 공식 기능이 완성된 것은 아닙니다. 상세 본문/옵션 이미지 지원을 일반화하지 않습니다. 가격비교 별도 도구의 등록은 계정 권한·실제 조회 성공을 보장하지 않습니다. 상품정보제공고시 카테고리·항목과 배송비 묶음·교환반품지 번호 읽기는 번호·이름만 돌려주고 주소·연락처는 돌려주지 않습니다.
- 11번가: `DOR_11ST_API_KEY`가 있을 때만 판매자 인증 READ 일부(등록 선택값, 상품 1건 요약, 기존 등록 상품의 정책 값)와 건별 승인 등록(WRITE, euc-kr XML 1건 + 확인 GET)이 구성됩니다. 판매자 전체 API 완료가 아닙니다. `k12-commerce-mcp-11st-public`의 공개 카테고리 GET opt-in은 인증값을 붙이지 않는 별개 경로입니다. 공개본의 11번가 등록기는 사진 주소로 자리 표시 주소(`https://k12-server.example.ts.net/11st/…`)만 받으므로 그대로는 다른 환경에서 등록에 쓸 수 없습니다([PUBLISHING](PUBLISHING.md)).
- 몰 등록 상태(`commerce_get_mall_listing_status`): 네이버·토스만 지원합니다. 최신 상품 목록 최대 3쪽(쪽당 50)에서 승인 기록 digest(토스는 관리 코드도)로 상품 하나를 찾아 상태 낱말만 돌려주고 상품 번호 원문은 내보내지 않습니다. 목록 3쪽 밖의 오래된 상품은 찾지 못할 수 있습니다(`match.kind = none`).

## 배포 및 로컬 종속성

- 다른 PC 설치와 원격 실제 운영은 아직 검증하지 않았습니다. GitHub 업로드만으로 네트워크 서버가 생기거나 앱에 연결되지 않습니다.
- 로컬 인증 파일은 대상 PC에서 준비해야 하며 저장소에 포함되지 않습니다.
- DOR 대시보드·승인 DB·승인 자산 저장소는 배포에 포함하지 않습니다. READ는 DOR 설치 없이 사용할 수 있지만 WRITE의 승인 연동은 별도 준비가 필요합니다.
- `commerce_list_documented_change_operations`의 K12 Wiki 스냅샷 기반 계약 목록은 해당 원본이 없는 다른 환경에서 `contract_not_configured`로 비가용할 수 있습니다. 내부 원본을 공개 패키지에 넣거나 임의 계약으로 대신하지 않습니다.
- 주문/클레임 ref와 이미지 ref는 서버 프로세스의 관측/메모리에 의존할 수 있습니다. 재시작·다른 프로세스로 그대로 옮겨 재사용하지 마세요.
- HTTP 코드가 있고 안전 가드도 있지만 공인 포트·터널·네트워크 변경·접근키 발급은 이번 공개 범위가 아닙니다.

**전체 공식 API 완료: false. 실제 쇼핑몰 변경: 이 공개 작업에서 수행하지 않음.**
