### 9/30 이후 누적 변경

- 상품 본문 읽기: 상세 HTML과 고시 값을 안전 검사 뒤 돌려주고, 실제 쇼핑몰 응답 모양에 맞춰 너무 엄격했던 검사를 고쳤습니다(돈·신원·개인정보 검사는 그대로 막음).
- 쿠팡: 할인 전 가격(`originalPrice`)을 판매가와 따로 읽습니다. 로켓그로스 주문 목록은 서명된 커서로 한 번 고정한 묶음을 나눠 돌려줍니다. 로켓그로스 상세의 옵션 속성 상한을 올리고, 상세 API를 쓸 수 없는 상품은 정직하게 표시합니다.
- 네이버: DOR 작업대에서 고친 상세 본문 블록(글·사진)을 등록 상세로 넣습니다. 표준형 옵션 미사용·빈 속성 분류를 처리합니다. 등록 거절 시 쇼핑몰이 적어 준 이유를 안전한 한 줄로 남깁니다.
- 토스: 등록과 읽기에서 쇼핑몰 거절 이유를 안전한 한 줄로 남깁니다. 등록 참고 읽기(고시·배송지 번호)를 더했습니다.
- 11번가: 판매자 인증 클라이언트(정해진 GET + 등록 POST 1개), 등록기, 기존 등록값 읽기를 더했습니다.
- 공통: 쇼핑몰 거절 문구를 화면에 보일 수 있게 줄바꿈·주소·전화·토큰 꼴을 걸러 내는 `safe_provider_message`를 더했습니다.

### 오늘 고친 것 (2026-10-10)

- 쿠팡 사진 100장 상한: 한 상품의 사진이 100장을 넘을 때 상품 읽기 전체가 실패하던 것을, 역할 순서(대표 > 추가·옵션 > 미분류 > 상세)로 100장을 골라 돌려주고 `image_count_truncated`로 표시하도록 바꿨습니다.
- 네이버 추가 사진: 등록 초안에 `optional_images`(최대 9장, 파일 증빙 필수, 같은 사진 거절)를 더했습니다. 비어 있으면 직렬화에서 빠져 옛 초안의 승인 digest가 그대로입니다.
